# 短信验证配置教程

本系统支持阿里云短信和腾讯云短信两个服务商，用于用户注册时的手机号验证。

---

## 功能说明

启用短信验证后，系统具备以下能力：

| 功能 | 说明 |
|------|------|
| 注册时手机号验证 | 用户填写手机号，发送 6 位验证码，通过后方可注册 |
| 手机号登录 | 用户可用手机号代替用户名登录 |
| 强制/可选两种模式 | 管理员可配置手机号是必填还是选填 |

验证码有效期 **5 分钟**，同一号码 **60 秒**内不可重复发送。

---

## 第一步：选择服务商并开通账号

### 方案 A：阿里云短信

1. 登录 [阿里云控制台](https://www.aliyun.com) 并完成实名认证
2. 搜索「短信服务」，开通产品（按量付费，约 ¥0.045/条）
3. 进入「短信服务控制台」

### 方案 B：腾讯云短信

1. 登录 [腾讯云控制台](https://cloud.tencent.com) 并完成实名认证
2. 搜索「短信」，开通产品（按量付费，约 ¥0.045/条）
3. 进入「短信控制台」，创建应用，记录 **SDKAppID**

---

## 第二步：创建签名

短信签名是发送方标识，显示在短信开头，如「【RAG知识库】您的验证码是 123456」。

### 阿里云

1. 短信控制台 → **国内消息 → 签名管理 → 添加签名**
2. 签名来源选「网站」，填写网站名称和域名
3. 上传营业执照或网站备案截图（审核 1-2 小时）
4. 审核通过后，记录**签名名称**（如：`RAG知识库`）

### 腾讯云

1. 短信控制台 → **国内短信 → 签名管理 → 创建签名**
2. 签名类型选「网站」，填写对应信息并提交
3. 审核通过后，记录**签名内容**（如：`RAG知识库`）

---

## 第三步：创建短信模板

模板定义了验证码短信的内容格式，审核通过后才可使用。

### 阿里云

1. 短信控制台 → **国内消息 → 模板管理 → 添加模板**
2. 模板类型选「验证码」
3. 模板内容填写：
   ```
   您的验证码为${code}，5分钟内有效，请勿泄露给他人。
   ```
4. 审核通过后，记录**模板 CODE**（如：`SMS_123456789`）

### 腾讯云

1. 短信控制台 → **国内短信 → 正文模板管理 → 创建正文模板**
2. 模板类型选「验证码」
3. 模板内容填写：
   ```
   您的验证码为{1}，5分钟内有效，请勿泄露给他人。
   ```
4. 审核通过后，记录**模板 ID**（如：`123456`）

---

## 第四步：获取 API 密钥

### 阿里云

1. 控制台右上角 → **AccessKey 管理**
2. 建议创建子账号 RAM 用户，只授予「AliyunDysmsFullAccess」权限
3. 创建 AccessKey，记录 **Access Key ID** 和 **Access Key Secret**

### 腾讯云

1. 控制台右上角 → **访问管理 → API 密钥管理**
2. 建议创建子账号，只授予短信相关权限
3. 新建密钥，记录 **SecretId** 和 **SecretKey**

---

## 第五步：安装 SDK

后端需要安装对应 SDK，在容器内执行：

```bash
# 阿里云
docker exec rag-knowledge-base-backend-1 pip install alibabacloud-dysmsapi20170525

# 腾讯云
docker exec rag-knowledge-base-backend-1 pip install tencentcloud-sdk-python-sms
```

---

## 第六步：填写系统配置

登录 RAG 系统（管理员账号），进入侧边栏 **系统配置** 页面，找到「短信验证」区块。

### 阿里云字段填写

| 字段 | 填写内容 |
|------|---------|
| 启用短信验证 | ☑ 勾选 |
| 注册时强制填写手机号并验证 | 按需勾选 |
| 短信服务商 | 阿里云短信 |
| Access Key ID | 第四步获取的 Key ID |
| Access Key Secret | 第四步获取的 Key Secret |
| 短信签名 | 第二步的签名名称，如 `RAG知识库` |
| 模板 Code | 第三步的模板 CODE，如 `SMS_123456789` |

### 腾讯云字段填写

| 字段 | 填写内容 |
|------|---------|
| 启用短信验证 | ☑ 勾选 |
| 注册时强制填写手机号并验证 | 按需勾选 |
| 短信服务商 | 腾讯云短信 |
| Secret ID | 第四步获取的 SecretId |
| Secret Key | 第四步获取的 SecretKey |
| App ID（SDKAppID） | 第一步创建应用时的 SDKAppID，如 `1400000000` |
| 短信签名 | 第二步的签名内容，如 `RAG知识库` |
| 模板 ID | 第三步的模板 ID，如 `123456` |

点击**保存**。

---

## 第七步：测试验证

1. 退出登录，进入注册页面
2. 若已勾选「强制验证」，手机号和验证码字段为必填；否则为选填
3. 填写手机号，点击「发送验证码」
4. 收到短信后填入验证码，完成注册
5. 登录时可直接使用手机号替代用户名

---

## 两种模式对比

| 模式 | 勾选项 | 注册体验 |
|------|--------|---------|
| 可选模式 | 仅勾选「启用短信验证」 | 手机号选填，填了才显示验证码框 |
| 强制模式 | 同时勾选「注册时强制填写手机号并验证」 | 手机号和验证码为必填项，不填无法提交 |

## 常见问题

**Q：签名/模板审核需要多久？**
A：阿里云和腾讯云工作日审核约 1-2 小时，节假日可能延长至次日。

**Q：发送提示「短信服务未启用」**
A：检查系统配置页「启用短信验证」是否已勾选并保存。

**Q：发送提示「请安装阿里云短信 SDK」**
A：执行第五步安装 SDK，安装后重启后端容器：
```bash
docker restart rag-knowledge-base-backend-1
```

**Q：发送失败，提示「阿里云短信发送失败」**
A：常见原因：
1. Access Key 权限不足，确认已授予 `AliyunDysmsFullAccess`
2. 签名或模板未通过审核
3. 签名名称/模板 CODE 填写有误（区分大小写）

**Q：腾讯云提示「App ID 错误」**
A：App ID 是 SDKAppID（纯数字，如 `1400xxxxxxx`），不是腾讯云账号 ID。

**Q：同一号码收不到第二条验证码**
A：系统限制同一号码 60 秒内只能发送一次，等待倒计时结束后重试。
