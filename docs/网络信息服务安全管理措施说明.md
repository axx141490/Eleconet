# 网络信息服务安全管理措施说明

**平台名称：** eleconet 知识库问答平台  
**网站域名：** www.eleconet.cn  
**文档日期：** 2026年4月

---

## 一、用户真实身份核验及注册信息留存措施

本平台用户注册时须填写用户名、邮箱，并可绑定经短信验证码验证的手机号（运营商实名）。系统通过第三方短信服务商完成手机号核验，注册信息（用户名、邮箱、手机号、注册时间）存储于服务器数据库，依法留存不少于六个月。

---

## 二、日志信息及用户发布信息记录的留存措施

服务器 Nginx 层记录每次 HTTP 请求的客户端 IP（网络源地址）、请求时间、请求类型（操作类型）、目标 URL（目标地址），日志文件本地留存；应用层数据库记录用户账号、操作时间及用户上传内容、对话记录，存储于服务器本地数据库。日志留存周期不少于六个月。

---

## 三、违法有害信息的防范处置及记录保存措施

本平台为私有知识库问答服务，不提供公开信息发布、转发、评论及通讯群组等功能，不存在用户间信息传播场景。用户上传文档及对话记录仅限本人访问，分享链接具有时效控制。平台通过用户账号管理、内容访问权限控制（JWT 鉴权）及管理员后台审核机制，防范违法内容扩散，相关操作记录留存于服务器数据库。

---

## 四、个人信息保护及防范违法有害信息传播技术措施

平台采用 HTTPS 加密传输保护用户数据，密码经 bcrypt 算法加密存储，通过 JWT Token 进行身份鉴权和访问控制，Token 设有有效期，支持管理员封禁异常账号。用户数据严格隔离，不开放公开内容发布渠道，不具备群组通知、公告推送等社会动员类功能，从技术架构层面规避相关风险。

---

## 五、为监管部门和执法部门提供技术、数据支持的工作机制

本平台数据存储于境内服务器，依法配合监管及执法部门的数据调取需求。平台设有管理员后台，可提供指定用户的注册信息、操作记录及内容数据；服务器日志（Nginx access log、应用日志）可按需导出提供。如接到依法履职的协查请求，企业负责人将在 24 小时内响应并提供相应技术与数据支持。

### 5.1 组织保障

企业指定 **[负责人姓名]** 为监管协助责任人，联系电话 **[手机号]**，邮箱 **[邮箱]**，收到依法协查函后承诺在 24 小时内响应并启动数据提供流程。

### 5.2 技术能力

平台用户注册信息（用户名、手机号、邮箱、注册时间、IP）、操作日志（登录记录、内容上传记录）及用户发布内容均存储于境内服务器数据库，可按需导出为结构化数据（CSV / SQL 格式）提供给执法部门。服务器 Nginx 日志完整记录访问行为，留存周期不少于六个月。

### 5.3 数据存储地

所有数据存储于中国大陆服务器，不进行跨境数据传输，满足数据本地化要求。
